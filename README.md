JohnnyEnterprise Event Rentals
Online booking request page for JohnnyEnterprise Event Rentals, offering chair and table rentals for weddings, birthdays, reunions, church events and backyard parties in Conyers, GA 30094.

Live site: https://jeatlrental.com

What it does
Shows the rental categories (chairs and tables) with photos
Lets customers send a booking request with:
Item quantities and categories
Rental dates
Event ZIP code (used to check the delivery zone)
Phone number and email
Preferred payment method and notes
Creates a booking reference number (for example, JE-2026-XXXXX) and a summary the customer can copy, download or email
Shows no prices online. Customers get their quote by phone
Works on phones and computers, in light and dark mode

The site is hosted on GitHub Pages and served at jeatlrental.com.

To update it:

Edit index.html (or upload a new version to replace it).
Commit the change.
Wait a minute or two for GitHub Pages to publish it.
Notes
Booking requests are sent by email. A request is not confirmed until Johnny calls the customer with a quote.
To change the business phone or email, search index.html for BIZ_PHONE_DISPLAY and BIZ_EMAIL.
